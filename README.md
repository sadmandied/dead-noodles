A responsive restaurant web landing page and dining catalog for **Dead Noodles**, featuring traditional Japanese ramen bowls, appetizers, drinks, and location discovery.

---

## 🌟 Highlights

- 🍜 **Signature Ramen Menu:** Showcase of authentic pork tonkotsu, spicy miso, and vegetarian noodle bowls with pricing and ingredient breakdown.
- 📱 **Fully Responsive Layout:** Built using modern **Bootstrap 5** grid systems, responsive cards, and mobile-first collapsing navigation.
- 📍 **Store & Location Locator:** Integrated hours, delivery services, and dining table reservation details.
- 🎨 **Modern Food Aesthetic:** High-resolution culinary imagery paired with dark Japanese noodle-bar styling.

---

## 🛠️ Technology Stack

- **HTML5:** Semantic document structure
- **CSS3:** Custom layout overrides and typography
- **Bootstrap 5.1:** Grid, navbar, cards, carousel, and utility classes
- **JavaScript:** Bootstrap interactive components

---

## 🚀 Quick Start

Open `index.html` directly in any web browser, or serve it using VS Code Live Server:

```bash
# Clone the repository
git clone https://github.com/sadmandied/dead-noodles.git

# Open the directory
cd dead-noodles

# Open in browser
start index.html
```
